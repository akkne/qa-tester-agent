# QA-агент: документация проекта

Это точка входа в проект. QA-агент проверяет один заранее настроенный приватный GitHub-репозиторий после push: анализирует изменение относительно ТЗ, добавляет тесты в отдельной ветке, запускает весь набор тестов и браузерные сценарии, публикует отчёт `revision/commit_<short-sha>.md`.

## Текущее состояние

Фаза М0 содержит компилируемый solution из восьми проектов, доменные правила, порты Application, адаптер системного времени, composition root, healthcheck хоста и шаблон демопроекта. API запуска, worker, GitHub, PostgreSQL, LLM, Docker и функциональность регистрации появятся в следующих фазах. Полный набор проверок проекта запускается командой `bash scripts/check.sh` в окружении с доступом к NuGet и локальным сокетам тестового раннера.
