# QA-агент: документация проекта

Это точка входа в проект. QA-агент проверяет один заранее настроенный приватный GitHub-репозиторий после push: анализирует изменение относительно ТЗ, добавляет тесты в отдельной ветке, запускает весь набор тестов и браузерные сценарии, публикует отчёт `revision/commit_<short-sha>.md`.

7. [Контракт API](contracts/api.md) — запуск и просмотр результата.

ТЗ подключённого проекта лежат в каталоге, который задаёт `SpecificationDirectory` его профиля (для `demo` — `docs/qa`). [Формат требований](specs/README.md) описан отдельно. Документация этого репозитория хранится только в `/docs`.

## Текущее состояние

М0–М6 завершены для одного приватного GitHub-репозитория. [Сквозная приёмка М6](m6-evidence.md) включает настоящие push, `codex exec`, исполняемые тесты, Docker, desktop/mobile Chromium, QA-ветку, отчёт и страницу результата. `bash scripts/check.sh` проверяет локальную сборку, тесты, PostgreSQL, Git-диапазоны и идемпотентность.
