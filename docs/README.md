# QA-агент: документация проекта

Это точка входа в проект. QA-агент проверяет один заранее настроенный приватный GitHub-репозиторий после push: анализирует изменение относительно ТЗ, добавляет тесты в отдельной ветке, запускает весь набор тестов и браузерные сценарии, публикует отчёт `revision/commit_<short-sha>.md`.

## Текущее состояние

М0 и М1 завершены. Локальный API запуска, PostgreSQL-очередь, worker с точным Git diff и Docker проверены командой `bash scripts/check.sh`; настоящий push доставлен из приватного GitHub-репозитория через self-hosted runner. Анализ LLM, исполняемые новые тесты и браузер входят в М2–М3. Локальный набор проверок включает сквозную проверку М1 с временными Git-репозиторием и PostgreSQL и требует работающий Docker.
