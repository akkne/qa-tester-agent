# М6: сквозная GitHub-приёмка с `codex exec`

Приёмка выполнена 22 октября 2026 года на приватном `akkne/qa-tester-agent`. `QaAgent.Host` работал на MacBook через LaunchAgent, GitHub Actions доставлял точные диапазоны SHA через self-hosted runner. Модель вызывалась только локальным `codex exec` под ChatGPT login. Отдельный API-ключ LLM не использовался.

## Два обновления продукта

1. Push [`c34e317..97b8569`](https://github.com/akkne/qa-tester-agent/actions/runs/39739644892) добавил требование `DEMO-REG-07`: пароль из одних пробельных символов должен отклоняться. Код намеренно проверял только длину. [Запуск `d3491fb6`](http://127.0.0.1:5080/runs/d3491fb6-04cf-4db8-930d-a213c6dafcef) через M2 сгенерировал три C# файла тестов, собрал их без исправлений и передал M3. Семь из 67 тестов упали на пробельных паролях; desktop и mobile Chromium прошли существующие браузерные сценарии. [QA-отчёт](https://github.com/akkne/qa-tester-agent/blob/qa%2F97b85697adfb-d3491fb604cf/revision/commit_97b85697adfb.md) опубликован, а ветка содержит только тесты и Markdown. M2 использовал 161097 входных и 4181 выходной токен.
2. Сгенерированные тесты приняты в `main`. Перед исправлением локальный прогон выбранных тестов дал 7 падений из 21; после добавления проверки `string.IsNullOrWhiteSpace` все 30 тестов `Demo.Tests` прошли. Исправление и тесты отправлены в push [`97b8569..2d8a8d6`](https://github.com/akkne/qa-tester-agent/actions/runs/39740428562).

На втором push обнаружена ошибка M2: сканер секретов ошибочно считал выражения `password = oneNonWhitespace ? ...` и `token = Regex.Match(...)` жёстко записанными секретами. Запуск `a667f12a` завершился `Blocked` до анализа. Исправление `5de282f` ограничило этот признак литералами, сохранив обнаружение реальных токенов и закрытых ключей; интеграционный тест воспроизводит исходный ложный сигнал. Следующий live push [`2d8a8d6..5de282f`](https://github.com/akkne/qa-tester-agent/actions/runs/39740826353) завершился `Passed`: 75 тестов без падений, оба Chromium viewport прошли, QA-отчёт опубликован.

Ручной повтор диапазона с исправлением продукта выявил вторую нестабильность: модель записала вымышленный ID требования. `881952f` добавил перечисление допустимых ID непосредственно в JSON-схемы трёх ответов Codex. `96c9e77` устранил ложное «покрытие не измерено» для строк объявления методов, у которых Coverlet не создаёт sequence point. Эти исправления прошли unit/integration tests и реальные push-проходы.

QA-ветка проверена через GitHub Contents API: файл отчёта существует; родитель QA-коммита равен `96c9e77a498b3f44a0c338f379f15a486885dccf`. Для доступа к loopback странице и файлам MacBook должен быть включён, а пользователь должен ввести `AgentApi__Key` как пароль HTTP Basic. Приватный GitHub-репозиторий требует входа в GitHub.

`bash scripts/check.sh` после исправлений прошёл: build, unit/integration/demo tests, проверки архитектуры, PostgreSQL, миграций, идемпотентности и двух хостов. GitLab в эту приёмку не входит.
