# ADR 0001. Границы и стек MVP

Статус: принято для демонстрационного MVP.

## Цель

До передачи задачи PM автоматически проверить **затронутую функциональность** по ТЗ и сохранить воспроизводимые результаты. Вход — зафиксированные `baseSha` и `headSha`, профиль проекта и ТЗ. Выход — QA-ветка от `headSha`, новые тесты-кандидаты, Markdown-отчёт и страница результата.

## Решения

| Область | Выбор для MVP | Причина |
| --- | --- | --- |
| Язык | C#, .NET 10 LTS | Один стек для сервиса и демопроекта |
| Хост | ASP.NET Core API + один `BackgroundService` | Локальный запуск и простой перенос на Linux |
| Хранение | PostgreSQL, EF Core/Npgsql | Очередь и результаты в одной транзакционной БД |
| Очередь | Строки PostgreSQL, один worker | Redis не нужен при одном обработчике |
| Git | GitHub API для метаданных, Git CLI для SHA, истории и diff | Проверка точного состояния репозитория |
| LLM | Один адаптер `ILlmClient`, модель через окружение | Провайдера можно заменить за портом; JSON проверяется схемой |
| Тесты | xUnit, Coverlet, Microsoft.Playwright для демопроекта | Исполняемые проверки и покрытие строк |
| Исполнение | Отдельные контейнеры приложения и тестов, тестовая БД | Изоляция от секретов оркестратора |
| Артефакты | Отчёт в Git; screenshots и traces локально | Доказательства доступны по ссылке из страницы результата |

GitHub Actions self-hosted runner на MacBook вызывает локальный API после push. Репозиторий и команды заранее известны из профиля. MVP поддерживает один доверенный приватный репозиторий, один стек, один LLM-провайдер, один worker, Chromium, desktop и один мобильный viewport.

## Не входит сейчас

Автонастройка произвольного проекта, GitLab, несколько стеков и проектов, облачный деплой, GitHub App, PR-комментарии, трекер, полный аудит неизменённого кода, самостоятельное исследование сайта, управление flaky-тестами и библиотекой кандидатов с автоматическим переносом. Кандидаты отслеживаются, но сливаются разработчиком.

Если срок сдвигается, сокращается оформление страницы результата. Автоматический запуск, реальные тесты, браузерная проверка и доказательства проблем обязательны.
