# Оставшиеся задачи

## Внешний блокер М2

- Для live-проверки М2 задать `Llm__BaseUrl`, `Llm__Model` и при необходимости `Llm__ApiKey` в игнорируемом `.env.demo`; сейчас эти значения пусты. Затем отправить push с новым требованием и проверить сохранённый `Analysis` в `GET /api/runs/{id}`. Offline-проверка с фейковым клиентом и настоящей сборкой тестов уже проходит.
- Тот же live push нужен для проверки сквозного перехода worker из М2 в М3 и сохранённого `Execution` в `GET /api/runs/{id}`. Сам исполнитель М3 отдельно проверен на двух зафиксированных SHA: исправном и с дефектом доступа; см. `docs/m3-evidence.md`.

## Внешний блокер М4

- После настройки LLM и live worker-прохода проверить GitHub push ветки `qa/<short-sha>-<run-id>`, ссылку `Publication.ReportUrl` в `GET /api/runs/{id}` и открытие `GET /runs/{id}` в браузере с HTTP Basic (пароль `AgentApi__Key`). Если Git credential helper не имеет права записи, задать `GitHub__Token` в игнорируемом `.env.demo`. Локальная публикация в bare Git remote и выдача отчёта уже проверены; см. `docs/m4-evidence.md`.
- Последняя реальная доставка workflow: запуск `baa1e67f-5363-415e-b6ef-07142ad229fb` завершился `BLOCKED` до М3/М4, так как `Llm:Model` и `Llm:BaseUrl` не настроены. После установки этих значений отправить новый push с требованием либо вручную вызвать workflow с новым диапазоном существующих SHA.

## Сквозная live-приёмка М5

- После настройки `Llm__BaseUrl` и `Llm__Model` выполнить в GitHub два последовательных push с новым требованием: первый должен сохранить тест-кандидат в QA-ветке и воспроизвести дефект, второй — после принятия теста и исправления — запустить всю базу и подтвердить исправление. Сверить `baseSha..headSha`, статус, расход LLM, screenshots/traces и ссылки отчёта на странице обоих запусков. Локальный цикл с теми же переходами прошёл; см. `docs/m5-evidence.md`.
- Последняя реальная доставка М5: запуск `61cb3065-e896-4c12-897b-2f1d11dde690` для `c14bf63..2d6a366` завершился `Blocked` до М2, поскольку `Llm__Model` и `Llm__BaseUrl` пусты. После настройки отправить новый диапазон; повтор старого вернёт прежний запуск и не переанализирует его.
- Записанная презентация локального цикла сохранена в `artifacts/m5-acceptance/m5-presentation.mp4` (40 секунд, без звука). После live-прохода при необходимости дополнить её записью реальных страниц GitHub/API.
