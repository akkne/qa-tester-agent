# Оставшиеся задачи

## Сквозная проверка после перехода на `codex exec`

- CLI `codex exec` и ChatGPT login проверены отдельным live-вызовом на хосте. После перезапуска `QaAgent.Host` с новым кодом отправить push с новым требованием и проверить `Analysis` в `GET /api/runs/{id}`. Старые значения `Llm__BaseUrl`/`Llm__ApiKey` в игнорируемом `.env.demo` не используются; при необходимости задать `Llm__CodexExecutable` и `Llm__Model`. Пустая модель использует настройку CLI. Offline-проверка с фейковым клиентом и настоящей сборкой тестов уже проходит.
- Тот же live push нужен для проверки сквозного перехода worker из М2 в М3 и сохранённого `Execution` в `GET /api/runs/{id}`. Сам исполнитель М3 отдельно проверен на двух зафиксированных SHA: исправном и с дефектом доступа; см. `docs/m3-evidence.md`.

## Внешний блокер М4

- После live worker-прохода с `codex exec` проверить GitHub push ветки `qa/<short-sha>-<run-id>`, ссылку `Publication.ReportUrl` в `GET /api/runs/{id}` и открытие `GET /runs/{id}` в браузере с HTTP Basic (пароль `AgentApi__Key`). Если Git credential helper не имеет права записи, задать `GitHub__Token` в игнорируемом `.env.demo`. Локальная публикация в bare Git remote и выдача отчёта уже проверены; см. `docs/m4-evidence.md`.
- Последняя реальная доставка workflow до смены адаптера: запуск `baa1e67f-5363-415e-b6ef-07142ad229fb` завершился `BLOCKED` до М3/М4, так как прежние `Llm:Model` и `Llm:BaseUrl` не были настроены. Нужен новый диапазон SHA; повтор старого вернёт прежний запуск.

## Сквозная live-приёмка М5

- С новым CLI-адаптером выполнить в GitHub два последовательных push с новым требованием: первый должен сохранить тест-кандидат в QA-ветке и воспроизвести дефект, второй — после принятия теста и исправления — запустить всю базу и подтвердить исправление. Сверить `baseSha..headSha`, статус, расход LLM, screenshots/traces и ссылки отчёта на странице обоих запусков. Локальный цикл с теми же переходами прошёл; см. `docs/m5-evidence.md`.
- Проверенная реальная доставка М5 до смены адаптера: запуск `61cb3065-e896-4c12-897b-2f1d11dde690` для `c14bf63..2d6a366` завершился `Blocked` до М2, поскольку прежние `Llm__Model` и `Llm__BaseUrl` были пусты. Диапазон `2d6a366..cde5998` также доставлен после повторного workflow и завершился с той же причиной. Нужен новый диапазон; повтор старого вернёт прежний запуск и не переанализирует его.
- Записанная презентация локального цикла сохранена в `artifacts/m5-acceptance/m5-presentation.mp4` (40 секунд, без звука). После live-прохода при необходимости дополнить её записью реальных страниц GitHub/API.
