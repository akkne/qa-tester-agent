# Оставшиеся задачи

Сквозная GitHub-приёмка М6 завершена: [доказательства](docs/m6-evidence.md). Внешних ключей или интеграций, блокирующих текущий сценарий, нет. GitLab не требуется.

- Расширить `browser/run.mjs` проверкой `DEMO-REG-07` на desktop и mobile: отправить пароль из одних пробелов, проверить видимую ошибку и отсутствие созданной учётной записи. В М6 этот дефект воспроизвели сгенерированные API/form тесты; текущий браузерный сценарий проверяет остальные шаги регистрации и доступа.
- При переходе от локальной демонстрации к удалённым пользователям опубликовать страницу результата и артефакты за аутентифицированным HTTPS endpoint. Сейчас страницы по адресу `127.0.0.1` доступны на MacBook с запущенным сервисом; приватные QA-ветки и отчёты доступны через GitHub после входа.
