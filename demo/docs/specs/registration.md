# DEMO-REG: регистрация и личный кабинет

Демо-приложение используется для проверки одного зафиксированного Git SHA. Все учётные записи и данные в нём синтетические.

| ID | Требование |
| --- | --- |
| DEMO-REG-01 | Пользователь регистрируется с email и паролем. Email нормализуется без учёта регистра и пробелов по краям; пустой, неверный email и пароль короче 12 символов отклоняются. |
| DEMO-REG-02 | Повторный email, включая вариант с другим регистром, не создаёт вторую запись и даёт понятное сообщение. |
| DEMO-REG-03 | Пароль хранится только в виде стойкого хеша; ответ API и страница не показывают пароль или хеш. |
| DEMO-REG-04 | Зарегистрированный пользователь входит с email и паролем и видит свой кабинет. Неверные данные не дают доступ. |
| DEMO-REG-05 | Анонимный пользователь не открывает кабинет; пользователь A не получает данные пользователя B по изменению URL или ID. |
| DEMO-REG-06 | Формы имеют подписи, ошибки понятны, а основные элементы — устойчивые `data-testid` для desktop и mobile Chromium. |

В М1 есть стартовая страница и smoke-тесты. Сама регистрация добавляется отдельным коммитом для демонстрации анализа в М2–М5.
